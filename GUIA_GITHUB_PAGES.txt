PUBLICAR GRATIS CON GITHUB PAGES
================================

Este paquete es una web estática: no necesita servidor, base de datos ni claves.

1. Entra a GitHub y crea un repositorio público, por ejemplo: pavi-etrans.
2. Sube TODO el contenido de esta carpeta, conservando las carpetas assets,
   data y python. index.html debe quedar en la raíz del repositorio.
3. Abre Settings > Pages.
4. En "Build and deployment", selecciona "Deploy from a branch".
5. Elige la rama "main", la carpeta "/ (root)" y pulsa Save.
6. GitHub mostrará la dirección pública cuando termine la publicación.

Después de editar archivos, vuelve a subirlos o realiza un nuevo commit. GitHub
Pages actualizará el sitio automáticamente.

Recomendación: antes de publicar, sustituye los datos demostrativos por los
conteos oficiales y verifica el nombre de todos los integrantes del Grupo 03.
